# 高三理科复习 · 使用说明（给学生）

在 WorkBuddy 里直接打字就行，不用记命令。

## 第一次（10 分钟）

说：**"我是高三，想用 rapid-learn 做理科复习，先帮我建档。"**

准备好：选科、各科课本封面（看教材版本）、学校各科复习到哪一章、最近一次考试的分数（有试卷照片更好）。

## 之后每次（30–45 分钟），三种用法选一种

| 你想做的 | 这样说 |
|---|---|
| 复习学校刚讲完的章节 | "今天复习物理第 X 章 电磁感应" |
| 复盘周测/月考 | "帮我复盘这张化学月考卷" + 拍照上传 |
| 搞懂一道错题 | "这道题我错了，帮我找原因" + 拍照 |

## 几个约定（这样效果最好）

- **它不会直接给答案**，会先问你怎么想的，再一级一级给提示。真的累了可以说"直接讲吧"。
- **拍照后它会先复述题目条件**，你核对一下再继续——图里的电路、受力、装置最容易看错。
- 每次结束会更新你的**薄弱点总表**（存在电脑的 `~/高三复习/` 文件夹里），下次开头会先复测上次没过关的点。
- 它出的题标【原创】，不是高考真题。物理、化学、生物以**福建卷和课本**为准，数学以**新高考Ⅰ卷**为准。
- 当天要交的作业它不会替你写，会讲一道同类题。
