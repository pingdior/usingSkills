# 多角度证据深析

这个 skill 有两个连续层次：六顶思考帽负责扩大问题空间，证据驱动分析负责判断哪些内容可以成立、哪些仍是猜测，以及下一步如何区分。六顶帽子产生的内容不是六份证据；情绪、风险、收益和创意都必须按其性质标注。

## 开始前

先用蓝帽明确：要解释、预测、决策还是反思；问题涉及的时间范围、利益相关者和可用材料；希望得到结论、方案还是核实计划。把“他不在乎我”“这个产品不行”改写成可观察行为或可检验命题，同时保留用户的体验表述。

资料不足时，给出有限判断，并询问最可能改变判断的一至三个问题。标注材料是事实记录、当事人自述、公开来源、模拟案例还是未知项。不得把角色代入写成知道他人内心，也不得把一轮分析说成已经验证。

## 使用入口

用户只需提供要分析的问题、事件或决策，以及已有材料和希望得到的结果。可以直接说“用多角度证据深析分析这个问题：……”。材料不完整时，先按已知边界工作，再询问最可能改变结论的少量问题。技能会自动完成六帽扩展、候选解释比较和核实计划，不要求用户预先整理成专业格式。

## 两层工作流

### 第一层：六帽扩展

用帽子作为问题清单，而不是让模型扮演六个“人格”。团队协作时，同一阶段让所有人使用同一顶帽子；个人分析时也保持分段，避免在同一句话里把事实、情绪和批评混成一个结论。

1. **白帽：事实与信息缺口。** 列出可观察事实、来源、时间、测量口径和未知项。来源写“初步发现”时，不能升级成最终结论；未核实的数字、研究和引语不能当确定前提。
2. **红帽：体验与直觉。** 记录用户或利益相关者报告的感受、直觉、担忧和厌恶。它们能说明体验、生成待检验假设，却不能自动证明外部事实或他人动机。
3. **黑帽：风险与失败机制。** 追问方案如何失败、什么反例会削弱当前解释、哪些混杂因素或隐性成本被忽略。风险是预测，除非有材料支持，不得写成已经发生。
4. **黄帽：价值与成立条件。** 找出已有方案或现象的收益、资源、韧性和可利用的机会，同时写明它们成立所需的条件，避免强行乐观。
5. **绿帽：替代解释与可能性。** 生成真正不同机制的假设、重新定义问题、反事实和低成本方案。创意阶段允许暂不判断，但输出进入下一层前必须标注为想法。
6. **蓝帽：整理与收束。** 归并重复内容，区分事实、体验、预测、价值判断和创意；提出二至四个机制不同的候选解释，不为形式制造虚假对立。

### 第二层：证据收敛

对蓝帽归并出的候选解释建立“支持证据—反证或缺口—可区分观察”对照。检查触发因素、维持因素、背景约束和个人责任，避免把相关、先后顺序或一次尝试当作因果证明。需要行为过程、功能、因果、反馈循环或框架审查时，查阅 [深析方法](references/protocol.md)。

优先寻找最有区分力的既有记录、相似情境反例和低成本可逆核实。写明什么结果会提高、降低或撤回主要解释；新的材料出现时，明确实际改变了哪一项结论。对数据比较检查定义、分母、时间窗、分配机制和分层变量发生时点；共同权重或分层描述不能替代因果识别。

## 输出

按问题复杂度选择快速扫描或深度模式。快速扫描每顶帽子只保留最重要的一至三点；深度模式再展开候选解释与核实计划。输出至少包含：当前最有依据的有限结论、关键材料与其边界、主要替代解释、最重要未知、下一步核实及改判条件。事实一致性、因果有效性、建议有用性分别报告。

如果追加追问没有增加证据、区分解释或改变行动，就停止继续堆叠视角。对涉及真实关系的建议，避免隐瞒、操控或制造冲突来试探他人；分析许可不等于联系当事人或执行外部实验的许可。需要练习和评估本 skill 时，读取 [核验协议](references/validation.md)。
