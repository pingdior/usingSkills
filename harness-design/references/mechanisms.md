# Harness 机制表

001–021 保留稳定编号，022–027 为长期运行增补；编号不表示必装顺序。先用 [主文件](../SKILL.md) 选择架构与风险边界，再用本表判断具体需要。
下列收益都是待在任务集上验证的设计理由，不包含通用最优阶段数、行数阈值或性能百分比。
相同问题可能由宿主能力、确定性代码或人工决策解决，不必都新增模型机制。

每行均按编号对应 [机制证据记录](mechanism-evidence.json) 的 source_behavior、existing_tests、runtime_benefit 三项。
这是证据分类，不是统一的可信度打分：设计建议不冒充源码行为，文章描述的已有测试不等于本仓库运行过测试，未测运行收益保持 unmeasured。
参考文章只覆盖其中一部分机制；没有定位到证据的条目明确记录为 design_recommendation / not_identified。

## 控制循环

| # | 机制 | 适用条件 / 前置能力 | 成本与失效模式 | 验收方向 |
|---|---|---|---|---|
| 001 | 观察—行动循环 | 下一步依赖运行观察；累积历史或显式状态重建均可 | 状态丢失、历史膨胀；固定流程未必需要循环 | 保留必要事实与行动结果，能据新观察改选动作 |
| 002 | 完成与停止判据 | 明确哪些结果可自动检验，哪些需评估或人工 | oracle 成本、误放行与误阻塞 | 假完成被拒；可交付结果不无限打磨；部分完成如实说明 |
| 003 | 分级预算 | 任务有成本或时长风险，宿主可统计 | 在途调用与重试漏计；软警告可能引起草率收尾 | 能取消和限制新动作；预算终止留下宿主可恢复状态；系统准入另见 023 |
| 004 | 进展检测与破环 | 可能出现重复或等价无效动作 | 指纹归一化误伤轮询、退避或合法重试 | 无进展循环受限，预期等待在截止时间内可继续 |
| 005 | 显式状态图 | 有条件转移、并发、等待、审批或恢复需求 | 状态过细、合并冲突、过期依赖、优先级饥饿 | 区分任务依赖 DAG 与执行状态图；成功前置才解锁，有效撤边生效；单位链长不冒充工期 |
| 006 | 计划工件 | 长任务、多依赖或需用户协作 | 计划过时、维护开销 | 新证据能触发留痕修订，短任务不强制生成 plan 文件 |
| 007 | 外化任务清单 | 任务跨较长上下文或恢复边界 | 遗漏、无理由删项、与计划重复 | 改范围有依据，未完成项和变更记录可追溯 |
| 008 | 持久化与恢复 | 任务需要跨中断续跑 | 本地快照不能覆盖外部副作用或排除旧执行者 | 核对未知动作；共享写入配合 024，反复重派配合 027；详情见运行契约 |
| 009 | 分离运行、验证与改进循环 | 不同循环有明确输入、权限与预算 | 反馈相互污染、未经批准修改策略 | 调度、运行验证和策略发布能分别停用与审计 |

## 上下文与工具边界

| # | 机制 | 适用条件 / 前置能力 | 成本与失效模式 | 验收方向 |
|---|---|---|---|---|
| 010 | 上下文取舍 | 信息选择成为成功率或成本瓶颈 | 凭「注意力」口号否决方案 | 比较信息完整性、任务成功、检索成本和时延；未知量明确 |
| 011 | 分层配置 | 项目或任务有合法配置差异 | 把配置覆盖误当权限覆盖 | 只有白名单键能被授权覆盖，上层强制约束仍有效 |
| 012 | 按需加载 | 引用可访问、检索质量可接受 | 仅凭文件名猜内容、漏召回、额外时延 | 必要事实能取回；不可访问或内容不全明确报告 |
| 013 | 上下文压缩 | 任务超过有效上下文或宿主需压缩 | 事实、来源、失败路径丢失 | 与压缩前关键事实对照；保留所需原文引用 |
| 014 | 主动压缩 | 能识别合适边界且宿主提供压缩能力 | 模型延迟或过早压缩 | 允许主动请求并保留容量兜底，不要求预先有固定阶段机 |
| 015 | 压缩契约 | 已采用有损压缩 | 通用字段过重；缺失后无限重试 | 保留目标、约束、授权范围、状态、证据、排除路径及理由、待办；失败有有限重试或交接 |
| 016 | 独立上下文 | 高噪声子任务可独立交付，或需要权限隔离 | 协调成本、上下文遗漏、相关错误 | 子任务有范围 / 证据 / 预算 / 返回格式；相对单 Agent 有可解释收益 |
| 017 | 外部工件存储 | 中间产物需寻址、共享或恢复 | 写了不读、版本漂移、存储泄露 | 产物有引用与版本，需要时能读回；不假定任何文件永不丢失 |
| 018 | 显式分页 / 裁剪 | 工具返回可能超出可用上下文 | 静默截断导致把局部当全部 | 声明是否完整、续取方法及已知范围；流式总量未知时如实注明 |
| 019 | 错误上下文修复 | 已定位错误观察或污染来源 | 局部重启也会丢正确信息；不能承诺必然纠正 | 保存可信事实和授权，隔离错误来源；验证新轨迹且避免重复副作用 |
| 020 | 缓存友好布局 | 供应商支持缓存且任务有稳定前缀 | 动态工具集、隐私隔离或权限变化影响缓存 | 测量实际命中和费用；不为缓存保留过期权限或多余工具 |
| 021 | 信任边界 | 混合指令与工具 / 网页 / 文件内容 | 标签只是提示，不是强制隔离 | 不可信内容不能扩大授权；用动作层与权限层共同验证 |

## 长期运行增补

| # | 机制 | 适用条件 / 前置能力 | 成本与失效模式 | 验收方向 |
|---|---|---|---|---|
| 022 | 增量事件索引 | 历史增长导致重复扫描；有稳定事件标识与提交顺序 | 重复追加、截断后旧索引、并发不一致 | 增量与全量结果相符；恢复后可重建；复用已有数据库索引 |
| 023 | 预测配额准入 | 多任务共享窗口配额，有新鲜观测与在途清单 | 预测偏低导致中断，偏高导致闲置 | 先影子记录，再验证中断、等待与有效完成；drain 不等于终止在途任务 |
| 024 | 世代号写入隔离 | 旧执行者可能在接管后恢复，且资源端支持原子资格检查 | 仅客户端检查存在竞态；外部系统可能不支持 fencing | 接管后旧资格写入被拒；并发认领只产生合法持有者；声明事务边界 |
| 025 | 机器告警生命周期 | 同一故障被持续机器巡检重复提出 | 过度归并吞掉新故障、严重度升级或独立求助 | 归并开放的同一问题；解决后复发重新提出；保留次数、时间和证据范围 |
| 026 | 上下文工作集 | 执行、修复、审阅或规划需可靠材料交接 | 原文与投影混淆、必读材料超容量、来源变化 | 材料范围和生产者可核查；反例不被挤掉；完整交付不冒充搜索充分或理解正确 |
| 027 | 跨轮次有界重派 | 后台会重复扫描失败任务或触发器 | 新 run 清空预算、只退避不停派、仅清标记不改条件 | 重派预算和停止标记持久化；显式恢复有依据；外部动作仍遵循幂等契约 |

上述机制及 005 的具体选择、默认参数边界与反例见 [长期运行机制](long-running-runtime.md)。

恢复和外部动作定义统一见 [运行契约](runtime-contract.md)，本表不维护第二套执行状态。

## 决策卡写法

记录「问题 → 替代方案 → 前置能力 → 适用范围 → 成本 / 预期收益 → 验收 → 撤回条件」。
可写未知或估计，并提出验证办法；高损失动作的必要边界不以故障已经发生或 ROI 已精确测得为前提。

### 002 完成与停止判据

- 可执行测试用于可判定部分；开放性质量采用经校准的评估、抽查或人类验收。
- 注入假完成、正常完成、部分完成三类案例，检查误判及是否能正确交接。
- 判据过严时先定位是实现问题、测量问题还是目标问题；不得由运行 Agent 擅自降低上层要求。

### 003 分级预算

- 预算包括模型、工具、重试、在途动作与子任务；先复用宿主账本。
- 软阈值提前交接，硬阈值禁止新增超范围动作；不能假定硬截止后仍能调用模型整理。
- 极短任务可仅使用宿主硬上限。若任务需要可恢复交接，持久状态应在正常执行时持续保存。

### 004 进展检测

- 动作指纹与状态变化结合；相同返回不自动等于错误。
- 测试无效等价调用、合法退避重试和等待外部状态变化；频率与截止时间属于任务契约。
- 放宽过激规则时保留预算兜底，禁止无限重启绕过总预算。
- 循环内动作重复与循环外任务重派分别计数；外层派发停止由 027 承担。

### 008 恢复

- 在模拟系统中注入「外部已生效、回执丢失」与「外部未生效」两条路径。
- 前者先核对已有结果；后者只在权限、预算和幂等契约允许时重试。
- 对不支持幂等且无法核对的操作，返回结果未知并交接，不能声称保证恰好一次。
- 测试恢复后的旧持有者迟到提交；幂等解决同一操作重复，024 解决执行资格过期，两者不能互相替代。

### 018 工具结果边界

- 比较完整返回、分页、已知总量截断与未知总量流式输出。
- 消费者必须知道证据是否完整；续取不可用时明确局限。
- 不必强制每个工具报告总行数；完整性标识和可行续取路径才是任务需要的契约。
- 工作集的完整性针对选定来源范围；审计投影与原文交付分开登记，具体见 026。
